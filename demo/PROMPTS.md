# Demo images

The 39 images in demo/images were generated by the author with AI
image tools: 33 cars, 3 buses and 3 trucks. They are not photographs
and not dataset images. No real dataset image is in this folder.

## Content credentials

The original files carried content-credential metadata naming the
generating tools. The 39 shipped files contain none: a string search
for OpenAI, SynthID, Google, Anthropic and C2PA found 0 matches, and
they have no EXIF or ICC data. Invisible pixel watermarks, if any,
were not checked.

## What the images show

The buses and trucks (demo_04, 14, 15, 24, 28, 39) show a burned-in
timestamp and road name. These overlays are AI-generated imitations of
CCTV text, not real recordings. The plates in all images are
AI-generated, in the Chinese format.

## Processing

Each image sits on a 640x480 canvas with grey (128,128,128) bars, no
crop and no stretch (scripts/prep_demo.py --canvas 640x480). The
embeddings come from scripts/embed_demo.py (ViT-B-16
laion2b_s34b_b88k). demo/labels.csv holds the author's labels. The
uncertain ones: demo_08 (type), demo_09 (view), demo_07, 08 and 31
(views), demo_22 (colour).

The zip stores the same 39 files in a folder named VeRi/image_test/ so
the service code can read it. It holds no VeRi data.

## Use

Plate boxes and readings, and the colour, type and weather outputs,
on these images are single examples, not measurements. The demo is
not evidence of model quality.
